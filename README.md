# MLH Global Hack Week: Hacktoberfest 2026

My challenge submissions for [MLH Global Hack Week: Hacktoberfest](https://events.mlh.io/events/14553-global-hack-week-hacktoberfest) (October 9–15, 2026).

| Folder | Challenge | Description |
|---|---|---|
| [`mini-app-copilot/`](mini-app-copilot) | Use GitHub Copilot to Build a Simple Application | Ritmo, a terminal task manager with a Pomodoro timer, built with GitHub Copilot in Python. |
| [`tiger-cloud-mcp/`](tiger-cloud-mcp) | Set up a Tiger Cloud service and create your first Hypertable · Integrate Tiger Cloud with your AI Agent with the Tiger CLI and MCP | A class grades database on Tiger Cloud (PostgreSQL + TimescaleDB hypertable), connected to GitHub Copilot in VS Code through the Tiger CLI and MCP server. |
| [`tiger-continuous-aggregates/`](tiger-continuous-aggregates) | Accelerate Dashboards with Continuous Aggregates | A continuous aggregate with monthly stats per subject (average, min, max) on the grades hypertable, refreshed every hour. |
| [`tiger-iot-sensors/`](tiger-iot-sensors) | Simulate an IoT sensor dataset for testing and development with Tiger Cloud | 24 hours of simulated temperature and CPU readings from 4 sensors in a hypertable, averaged every 30 minutes with `time_bucket`. |
| [`tiger-pgvector/`](tiger-pgvector) | Implement AI-Powered Vector Search with pgvector | Study notes with vector embeddings in a hypertable, searched by similarity (cosine distance) and filtered by date. |
| [`tiger-financial-data/`](tiger-financial-data) | Ingest real-time financial data into Tiger Cloud | FinTrack, a Django app that streams live crypto trades from Coinbase into a hypertable, builds 1-minute candles with a continuous aggregate and shows them on a live dashboard. |
